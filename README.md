# 📌 Project Overview

Financial institutions process thousands of loan applications every year, making it difficult to monitor lending performance, assess portfolio quality, identify credit risk, and understand customer borrowing behaviour using static reports.

This project presents an **interactive Loan Portfolio Performance Dashboard** developed in **Power BI** that transforms raw lending data into meaningful business intelligence.

Instead of creating a single dashboard, the solution was designed as a **three-page analytical reporting application** consisting of:

- 📈 Executive Dashboard
- ⚠️ Loan Risk Analysis
- 👥 Customer Insights

The report combines **Power Query**, **advanced DAX**, **interactive visualisations**, and **business storytelling** to help decision-makers monitor portfolio performance, identify high-risk loan segments, and analyse customer borrowing patterns through a clean and intuitive reporting experience.

# 💼 Business Problem

Loan portfolio data contains valuable insights, but traditional reports often make it difficult to monitor lending performance, evaluate portfolio quality, and identify risk patterns efficiently.

This dashboard centralises portfolio monitoring into a single Business Intelligence solution, enabling stakeholders to explore lending performance, customer behaviour, and portfolio risk through interactive reporting.

# 🎯 Business Objectives

- Monitor overall lending performance
- Evaluate portfolio quality
- Measure funding efficiency
- Identify high-risk loan segments
- Analyse customer demographics
- Understand borrowing behaviour
- Support data-driven lending decisions

---

# 🏗 Dashboard Architecture

### 📈 Executive Dashboard
Provides a high-level overview of lending performance through KPIs, monthly trends, geographical analysis, portfolio composition, and executive insights.

### ⚠️ Loan Risk Analysis
Focuses on portfolio quality by analysing loan grades, bad loan percentage, loan purposes, and home ownership risk.

### 👥 Customer Insights
Explores customer demographics, income groups, home ownership, loan purposes, and borrowing behaviour.
