# Dataset

The original dataset used in this project exceeds GitHub's recommended file size for direct upload.

## Dataset Information

- **Dataset:** Lending Club Loan Dataset
- **Records:** ~38,000+ loan applications
- **Format:** CSV
- **Domain:** Financial Services / Lending Analytics

## Fields Used

- Loan Amount
- Funded Amount
- Loan Status
- Interest Rate
- Loan Grade
- Purpose
- Home Ownership
- Annual Income
- Debt-to-Income Ratio
- Issue Date
- State
- Employment Length

## Note

The complete dataset is not included in this repository due to GitHub file size limitations.

If you would like to reproduce this dashboard, you can use the publicly available Lending Club Loan Dataset from Kaggle or another public source with a similar schema.
